# Abuzar Khan Portfolio Website

## Important: keep images with the website
The `assets` folder contains the portfolio dashboard images. Do not upload only `index.html`; upload the entire folder/repository, including `assets/`.

## Preview locally
Open `index.html` in a browser. Keep the `assets` folder next to it.

## Deploy on Vercel
1. Upload the complete contents of this folder to a GitHub repository.
2. Import the repository in Vercel.
3. For a plain static website, leave the framework preset as `Other`, with no build command and no output directory required.
4. Deploy.
